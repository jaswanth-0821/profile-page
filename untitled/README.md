# home

I’m Jaswanth Reddy, a computer vision and NLP researcher with a BTech from IIT Tirupati. I grew up riding oxcart through the dusty lanes of my village in India, a small memory that still grounds me in where my journey began

My focus is on building practical, reliable ML models. I’ve worked across 3D vision, tracking, and language technologies.

I began my research journey at [VAL(IISc)](https://val.cds.iisc.ac.in/), India’s top-ranked computer vision group on [CSRankings 2024](https://csrankings.org/#/fromyear/2014/toyear/2024/index?ai\&vision\&mlmining\&nlp\&inforet\&in). There, I worked on 3D reconstruction and object manipulation using Neural Radiance Fields and Gaussian Splatting.

After IISc, I joined [ViSAL Lab](https://sites.google.com/iittp.ac.in/ee-spcv-lab?usp=sharing), where I develop a memory-based long–short term tracking model for transformer architectures. My work spanned both single and multi-object tracking.

I’m currently at [AutoAlign.ai](https://www.autoalign.ai/), building next-generation NLP and GenAI systems focused on trustworthiness, safety, and production reliability. My work includes: \
• Designing LLM guardrails for sensitive and high-stakes workflows\
• Building RAG and Agentic pipelines, evaluation systems, and scalable data annotation frameworks\
• Developing response modeling, code extraction, and intelligent document understanding systems\
• Creating end-to-end ML pipelines for customer intelligence, automation, and decision systems

Across projects, I’ve worked on LLM orchestration, Agentic workflows, vector search systems, predictive modeling, and AI infrastructure that bridges research with deployment.

If you’re building in computer vision, NLP, GenAI, or applied ML systems, I’d love to connect.
